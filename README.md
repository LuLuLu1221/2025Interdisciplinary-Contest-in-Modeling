# 2026 ICM Problem D - NBA 球队管理建模

本仓库整理自 2026 ICM Problem D 的洛杉矶湖人队案例材料，主题为在竞技成绩与商业价值之间进行动态决策。

## 目录说明

- `美赛/论文原文/`：正式论文 PDF。
- `美赛/论文源稿.tex`：论文 LaTeX 源稿。
- `美赛/D题_湖人球队管理模型/`：D 题的核心模型、代码、数据和可视化结果。
- `美赛/球员数据/`、`美赛/联盟与球队数据/`、`美赛/交易方案数据/`：建模使用的数据资料。
- `美赛/可视化图表_汇总/`、`美赛/补充数据与图表/`：汇总图表和补充分析材料。
- `美赛/论文分章节草稿/`：保留的分章节论文草稿，供追溯使用。

已移除内容哈希完全一致的重复副本，并通过 `.gitattributes` 保护表格、图片和 PDF 等二进制文件。
